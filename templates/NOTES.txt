Thank you for installing {{ .Chart.Name }}!

Your release is named: {{ .Release.Name }}

To get the status of your deployment:

  kubectl get pods -l "app.kubernetes.io/name={{ include "rstmdb.name" . }},app.kubernetes.io/instance={{ .Release.Name }}" -n {{ .Release.Namespace }}

{{- if eq .Values.service.type "ClusterIP" }}

To connect to rstmdb from within the cluster:

  Host: {{ include "rstmdb.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local
  Port: {{ .Values.service.port }}

To port-forward the service locally:

  kubectl port-forward svc/{{ include "rstmdb.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }} -n {{ .Release.Namespace }}

Then connect using:

  rstmdb-cli -s localhost:{{ .Values.service.port }} ping

{{- else if eq .Values.service.type "NodePort" }}

To connect to rstmdb using NodePort:

  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "rstmdb.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo "rstmdb is available at $NODE_IP:$NODE_PORT"

{{- else if eq .Values.service.type "LoadBalancer" }}

To connect to rstmdb using LoadBalancer:

  NOTE: It may take a few minutes for the LoadBalancer IP to be available.
  You can watch the status by running:
  kubectl get --namespace {{ .Release.Namespace }} svc -w {{ include "rstmdb.fullname" . }}

  export SERVICE_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "rstmdb.fullname" . }} --template "{{"{{ range (index .status.loadBalancer.ingress 0) }}{{.}}{{ end }}"}}")
  echo "rstmdb is available at $SERVICE_IP:{{ .Values.service.port }}"

{{- end }}
